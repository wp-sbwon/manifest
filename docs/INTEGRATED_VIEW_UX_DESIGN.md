## 📋 패널 구성

### 1. **상단 헤더 (Dashboard)**
- Architecture Match %
- Tasks 진행률
- Active Agents 수
- **위치**: 최상단 고정
- **업데이트**: 5초마다

### 2. **컨텍스트 바**
- 현재 활성 agent들의 활동
- **위치**: Dashboard 바로 아래
- **업데이트**: 2초마다

### 3. **사이드바 (왼쪽)**
- **Task Tree**: 모든 task 목록, 상태, 진행률
- **필터링/검색**: 상태별, 키워드 검색
- **선택**: Task 클릭 시 상세 정보 표시

### 4. **메인 영역 (오른쪽) - 탭 구조**

#### 탭 1: **Structure View**
- **Hierarchy**: 프로젝트 구조 트리
  - 파일/디렉토리 옆에 관련 task 표시
  - 예: `src/manifest/ [task-1] ⚡`
- **Graph**: 컴포넌트 관계 그래프
  - 컴포넌트 옆에 task 표시
  - 진행 중인 task는 하이라이트

#### 탭 2: **Agent Status**
- 각 활성 agent의 상세 정보:
  - Task ID, Agent Type
  - Status, Current Stage
  - **CPU 사용량** (새로 추가)
  - **메모리 사용량** (새로 추가)
  - **실행 시간** (새로 추가)
  - Channel 이름
  - 리소스 사용량 그래프 (선택적)

#### 탭 3: **Task Progress**
- 선택된 task의 상세 진행상황:
  - Worker Squad stages 진행률
  - 각 stage 상태
  - 수정된 파일 목록 (task와 연계)
  - Git diff 링크

#### 탭 4: **Agent Channels**
- 채널 선택 버튼
- 선택된 채널의 로그 출력
- 실시간 스트리밍

## 🎯 주요 특징

### 1. **프로젝트 구조와 Task 연계**
- 파일/디렉토리 옆에 관련 task 표시
- 컴포넌트 그래프에서 task 진행상황 하이라이트
- Task 선택 시 관련 파일/컴포넌트 자동 하이라이트

### 2. **Agent 상세 정보**
- CPU, 메모리, 실행 시간 표시
- 리소스 사용량 모니터링
- Container 모드에서 상세 정보 제공

### 3. **실시간 업데이트**
- 모든 패널이 주기적으로 자동 업데이트
- Task 상태 변경 시 즉시 반영
- Agent 시작/종료 시 자동 갱신

### 4. **독립적인 패널**
- 각 패널은 독립적으로 작동
- 패널 크기 조절 가능 (향후)
- 필요한 패널만 표시 가능 (향후)

## 💡 구현 우선순위

### Phase 1 (필수)
1. ✅ Agent Status 탭 추가 (CPU, 메모리, 실행 시간)
2. ✅ 프로젝트 구조에 task 표시
3. ✅ Task 선택 시 관련 파일 하이라이트

### Phase 2 (개선)
1. 리소스 사용량 그래프
2. 패널 크기 조절
3. 패널 표시/숨김 토글

## 📝 참고사항

- **"여러 창을 띄워놓는 느낌"**: 각 패널이 독립적으로 작동하지만 한 화면에 모두 표시
- **통합 뷰 아님**: 각 정보는 독립적인 패널로 구성, 통합 분석은 사용자가 직접 수행
- **확장 가능**: 필요에 따라 새로운 패널 추가 가능
