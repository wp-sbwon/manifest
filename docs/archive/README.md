# 문서 아카이브

이 디렉토리는 완료되었거나 구버전 문서들을 보관합니다.

## 버전 관리

- **v1.0**: 2026-01-24 이전 문서들 (초기 구현 및 리뷰 문서)

## 아카이브된 문서 목록

### 구현 완료 문서 (v1.0)
이 문서들은 계획되었던 기능들이 모두 구현 완료되어 아카이브되었습니다.

- `MISSING_IMPLEMENTATIONS.md` - 누락된 구현 사항 (✅ 모두 완료)
- `ADDITIONAL_MISSING_UI_FEATURES.md` - 추가 누락된 UI 기능 (✅ 모두 완료)
- `IMPLEMENTATION_SUMMARY.md` - Phase 1 구현 요약
- `FINAL_IMPLEMENTATION_REPORT.md` - 최종 구현 보고서
- `CRITICAL_IMPLEMENTATION_SUMMARY.md` - Critical 기능 완료 요약
- `HIGH_PRIORITY_IMPLEMENTATION_SUMMARY.md` - High Priority 기능 완료 요약

### 설계/계획 문서 (v1.0)
구현이 완료되어 더 이상 활성 계획이 아닌 문서들입니다.

- `INTEGRATED_VIEW_UX_DESIGN.md` - 통합 뷰 UX 디자인 (✅ 구현 완료)
- `COMPONENT_GRAPH_IMPROVEMENT_PROPOSAL.md` - 컴포넌트 그래프 개선 제안 (✅ 구현 완료)
- `FINAL_PLAN.md` - 최종 계획 문서

### 리뷰/검토 문서 (v1.0)
코드베이스 리뷰 및 검토 문서들입니다.

- `CODE_REVIEW.md` - 코드 리뷰 (리팩토링 관점)
- `CODE_REVIEW_SUMMARY.md` - 코드 리뷰 요약
- `CODEBASE_REVIEW_FINDINGS.md` - 코드베이스 리뷰 결과
- `PROJECT_REVIEW.md` - 프로젝트 리뷰
- `CODEBASE_AUDIT.md` - 코드베이스 감사

### 우선순위/요구사항 문서 (v1.0)
구버전 우선순위 및 요구사항 문서들입니다.

- `MANIFEST_REQUIREMENTS.md` - Manifest 요구사항
- `REMAINING_FEATURES.md` - 남은 기능 목록
- `CRITICAL_PRIORITIES.md` - Critical 우선순위
- `REVISED_PRIORITIES.md` - 수정된 우선순위

### 상태 문서 (v1.0)
구버전 상태 문서들입니다. 최신 상태는 `PROJECT_STATUS.md`를 참조하세요.

- `TASK_MANAGER_STATUS.md` - Task Manager 상태 (→ PROJECT_STATUS.md에 통합)
- `REFACTORING_STATUS.md` - 리팩토링 상태 (→ REFACTORING.md에 통합)
- `CURRENT_VISIBILITY_STATUS.md` - 현재 가시성 상태 (→ PROJECT_STATUS.md에 통합)

### 아키텍처 문서 (v1.0)
구버전 아키텍처 문서입니다. 최신 아키텍처는 `ARCHITECTURE.md`를 참조하세요.

- `MANIFEST_ARCHITECTURE.md` - Manifest 아키텍처 (→ ARCHITECTURE.md에 통합)

### 프로젝트 구조 문서 (v1.0)
상세 프로젝트 구조 문서들입니다. 요약은 `PROJECT_STRUCTURE.md`를 참조하세요.

- `MANIFEST_PROJECT_STRUCTURE.md` - 상세 컴포넌트 목록
- `MANIFEST_PROJECT_VISUALIZATION.md` - ASCII 시각화
- `MANIFEST_PROJECT_VIEW_STATUS.md` - UI 표시 상태

## 문서 참조

아카이브된 문서들은 Git 히스토리에 보존되어 있으며, 필요시 참조할 수 있습니다.

최신 문서는 `docs/` 디렉토리의 루트에 있습니다:
- `PROJECT_STATUS.md` - 최신 프로젝트 상태
- `PROJECT_STRUCTURE.md` - 프로젝트 구조 요약
- `ARCHITECTURE.md` - 최신 아키텍처
- `README.md` - 문서 인덱스
