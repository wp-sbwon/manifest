# UX & 가시성 개선 계획 (Claude Code 스타일 + Project Visibility)

**작성일**: 2026-01-24
**목표**: Claude Code/OpenCode 스타일의 개발자 친화적 UX와 프로젝트/태스크 현황의 극대화된 가시성 확보

---

## 🎨 1. Command Center (명령어 중심 인터페이스) 강화
*   **목표**: 대화와 명령이 자연스럽게 이어지는 인터페이스
*   **개선 사항**:
    *   입력창 명령어 자동 완성 및 제안 기능 보강
    *   명령 실행 시 UI 요소(태스크 트리, 그래프) 즉시 반응(Reactive Update)
    *   현재 활성화된 태스크 컨텍스트 자동 유지

## 📊 2. Dashboard View (프로젝트 현황판) 도입
*   **목표**: 프로젝트 건강 상태와 진행률을 한눈에 파악
*   **개선 사항**:
    *   **Drift Status**: 설계와 코드의 일치율 시각화 (예: `Match: 95%`)
    *   **Task Velocity**: 완료된 태스크 vs 남은 태스크 요약 지표
    *   **Active Agents**: 현재 가동 중인 에이전트 수 및 상태 표시
    *   상단 헤더 또는 별도 대시보드 위젯으로 상시 노출

## 🛠️ 3. Task-Centric UX (태스크 중심 워크플로우)
*   **목표**: 태스크를 선택하는 것만으로 모든 관련 정보 통합 제공
*   **개선 사항**:
    *   `TaskTreeView`에서 태스크 선택 시 인스펙터(Inspector) 자동 전환
    *   선택된 태스크의 **에이전트 로그, 수정된 파일 목록, Git Diff**를 한 화면에 모아서 표시
    *   태스크 상세 정보에서 즉시 에이전트 재시작 또는 롤백 가능

## 🔍 4. Lightweight Context Bar (컨텍스트 가시화)
*   **목표**: 에이전트가 무엇을 하고 있는지 투명하게 공개
*   **개선 사항**:
    *   에이전트가 현재 읽고 있는 파일 목록 실시간 표시
    *   참조 중인 Blueprint 노드 하이라이트
    *   하단 상태바(Status Bar)를 활용한 에이전트 "시선" 추적

## 🚀 실행 로드맵
1.  **Step 1**: 상단 상태바 강화 및 실시간 요약 지표 추가
2.  **Step 2**: 태스크 선택 시 인스펙터 정보 통합 연동 (Log + Diff + Files)
3.  **Step 3**: 명령어 입력창 피드백 및 반응성 개선
